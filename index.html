Open agentic website · one grounded capability

Receipts are checked by arithmetic,
not by opinion.

This site publishes a single capability any agent can call: given a receipt's line items, it returns the duplicate charges and the gap between the printed total and what the items actually add up to. Every number is plain code, so the answer can be re-checked by anyone. It never estimates what a price should have been.

The capability

Declared in agent-manifest.json and receipt_audit.network.json. It runs in your browser; no server sees the data.

audit_receipt

Input: the line items and, if printed, the total. Output: duplicates, item sum, printed total, difference, suspect overcharge.

What it will not do: estimate a fair price, infer tax, read a photo, contact a merchant, or tell you whether to dispute a charge. Those need data or authority this site does not have.

Why a capability and not an app

A receipt audit is exact work: the answer is either right or wrong, and a language model has no better claim on it than arithmetic does. So the useful thing to publish is the check itself, as a typed capability other agents can call when they need a number verified. The chat on this page is one caller; another site's agent is another.

This site follows the Worldwide Agentic Web MVP profile: a public network descriptor, a browser runtime, typed capabilities with declared effects, and no server holding your data.
